# 歌词导出

## 入口

- 单首：音乐库歌曲的「更多 → 导出歌词」，无需先播放该歌曲；也可使用播放详情的「更多 → 导出当前歌词」。
- 全部：设置中的「导出全部歌词」，显示当前媒体库中可导出的歌曲数量。
- macOS 使用系统保存窗口，Android 使用系统文档保存界面。用户选择文件名及保存位置，无需新增全部文件访问权限。其他平台暂不支持。

## 文件与校准规则

- 单首保存 UTF-8 编码 `.lrc`，包含标题、艺术家、专辑及毫秒级时间标签。
- 全部保存 `Lumio-全部歌词.zip`，每首一个 LRC，序号避免重名覆盖；自动跳过无有效歌词的歌曲并报告数量。包含当前媒体库中已有的歌词，不限于手动导入来源，不临时联网补歌词。
- 导出的时间标签 = 原时间标签 − 已保存的本曲偏移；本机全局偏移和校准面板未保存的草稿不参与。
- 校准后早于零秒的行按 `00:00.000` 输出，完成提示报告这类行数，不悄悄删除歌词。
- 导出文件可重新通过「导入歌词」绑定到歌曲；重新导入会清除旧的单曲校准，避免重复偏移。
- 不覆盖源媒体或原歌词；只写入用户选定的导出目标。若用户自行选择已有文件，遵循系统保存窗口的覆盖确认。
- ZIP 只包含歌词文件，不包含音视频、播放记录、文件路径、账户信息或应用设置。

## 实现与保护

- Dart 统一生成 LRC，使用本机缓存的 `archive` 依赖生成 ZIP；编码和压缩在后台 isolate 执行。
- `lumio/media_library.exportLyrics` 传递文件名与字节；原生侧进行类型、大小校验并在后台写入，返回 completed / cancelled / failed。
- 文件名清理路径分隔符、控制字符和常见不合法字符，限制 UTF-8 文件名长度；中文和表情保持原样。
- 导出使用点击时的媒体快照；防重复点击；没有歌词时禁用入口。取消不写入，失败不报成功。
- 单次未压缩歌词总量和输出文件均限制 32 MB，ZIP 最多 65535 首；超过限制提示分首导出，不截断数据。系统保存后端中断可能留下未完成文件，失败后可重新导出。
- 本次补充 LRC 长分钟数解析，导出超过 99 分钟的时间标签后仍能重新导入。
