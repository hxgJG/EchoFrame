# Lumio PRD 缺口收敛实施计划

**目标：** 在不接入未确认在线数据源、不修改用户真实媒体文件的前提下，完成当前仓库内可安全实现和验证的高价值功能，并统一文档状态。

**基线：** `docs/Lumio_PRD_v0.5.md`、`docs/TECHNICAL_PLAN.md`、`docs/FEATURE_STATUS.md`

## 全局约束

- 保留当前未提交改动，不回退用户工作。
- 默认中文界面。
- 不新增 Widget/页面单元测试；纯 Dart 行为遵循测试先行。
- 不执行真实媒体删除、移动、重命名、标签写回。
- 不接入未确认的网络数据源。
- 不修改或提交个人签名材料。
