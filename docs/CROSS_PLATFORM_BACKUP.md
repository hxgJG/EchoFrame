# Lumio 跨端数据备份与媒体扩展设计

macOS 与 Android 使用相同的应用数据备份格式，支持本地导出导入及 WebDAV 云端上传恢复。当前只备份应用数据，不备份真实音视频或封面文件；未来可以增加媒体附件，但不能让旧客户端误把不完整备份当成完整备份。

## 当前备份范围

- 设置、正式歌词、歌词时间偏移、歌词草稿、歌词包与歌曲名称别名。
- 歌单、收藏、播放次数、随机播放权重、队列及播放进度。
- 视频字幕及字幕工作台项目。Android 保留工作台项目数据供再次导出，不启用桌面编辑功能。
- 媒体元信息和关联标识，不包含真实音视频、封面、旧设备路径、系统文件授权、设备身份私钥或 WebDAV 应用密码。

备份未加密。卸载会删除 App 内接收的媒体；使用者必须另行保存这些文件，不能把“数据备份成功”理解成“媒体文件已备份”。

## 统一格式

普通单卷 ZIP 只包含 UTF-8 `lumio-backup.json`，使用不压缩模式。清单声明 `format: lumio-data-backup`、`version: 2`、`mediaMode: references`、`attachmentSchemaVersion: 1`、导出平台、导出时间、应用状态和空 `files` 列表。平台字段仅作来源提示，不限制新版跨端恢复。应用状态的 `schemaVersion: 2` 与备份容器版本是两个不同的版本号。

应用元数据最多 128 MiB，云端 ZIP 最多 132 MiB。现有旧版 v1 完整备份仍按原规则读取，包括 2 GiB 上限和同平台限制；新版导出默认使用 v2。两台设备都需要支持 v2 的新版本，旧客户端不能读取新版数据包。

媒体使用持久化的 32 位十六进制标识。清单中的媒体 ID 为 `portable-<标识>`，路径为 `lumio-backup://media/<媒体ID>`。歌单、队列、隐藏记录及播放记录引用统一 ID，而不是 Android MediaStore ID 或 Mac 路径。

每个媒体引用保留原始文件名、文件大小、时长、名称别名以及可获取的 SHA-256 文件指纹。修改展示名称不改变关联标识。文件指纹按原始文件字节计算，不上传文件；文件标签或文件内容发生变化也会改变指纹。

## 恢复和后续关联

恢复前校验 ZIP 路径、条目数量、CRC、媒体引用、项目格式和资源上限。下载还需校验长度和 SHA-256。确认后覆盖应用设置及业务记录，不进行实时双向合并；本机文件授权、扫描目录和设备身份保留，不自动播放，不删除原文件。本机已接收的媒体索引保留，避免现有文件成为孤立文件。

匹配优先使用一致的文件指纹；无法取得指纹时，以文件名、大小、时长或名称别名、艺术家、大小、时长组合进行唯一匹配。跨平台探测的时长允许 1 秒误差。双方已知指纹冲突时禁止降级匹配，多候选或多条备份指向同一候选时不自动覆盖。元信息相同但实际上不同的文件仍可能无法可靠区分；有歧义的记录保留，不能保证自动关联所有媒体。

没有文件的记录保留歌词、歌单和播放进度，后续扫描、Finder 打开视频或接收互传文件时再次关联。未关联记录不能播放，也不会进入原生播放队列或随机播放池。成功关联后按备份恢复名称、艺术家、专辑及其他业务记录。

原生指纹计算使用后台线程及有界流式读取，每批最多 5000 个候选、单文件最多 512 MiB。超大文件、无授权、读取失败或批次外的文件可保留无指纹引用，使用明确的元信息匹配；不扫描整首歌的 PCM，不阻塞音频处理线程。

字幕项目不携带旧文件授权；在桌面工作台使用“重新选择视频”恢复预览。元数据恢复不授权访问新设备上的任意路径。

## WebDAV 云端存储

设置中的“云端备份（WebDAV）”支持 HTTPS 地址、账号、应用密码及根地址下一级备份目录。默认预填坚果云 WebDAV 地址；坚果云使用邮箱和第三方应用密码，见[官方配置说明](https://help.jianguoyun.com/?p=2064)。不需要 Lumio 账号，但服务商自己的账号和额度仍然适用。

仅手动测试连接、上传和刷新下载，不在启动时联网。应用密码保存在本机备份状态之外：macOS 配置目录权限 700、文件权限 600；Android 使用应用私有的 noBackup 目录。该本机配置不是加密保险库，不进入跨端备份，换设备或卸载后重新配置。

每次上传创建独立时间戳文件：先 PUT 隐藏暂存文件，再 MOVE 到正式 ZIP，最后发布 `.zip.json` 校验清单。MOVE 禁止覆盖。列表仅显示已发布清单的备份，最多显示最近 50 个，不自动清理历史；远端不完整暂存文件或已上传但未发布清单的 ZIP 可在服务商端手动清理。服务端须支持 PROPFIND、MKCOL、PUT、MOVE 和 GET，不承诺兼容所有供应商差异。

HTTP 跳转不会转发密码，拒绝明文 HTTP，不忽略 TLS 证书错误。响应有大小上限；下载为流式写入，可取消，有连接与无数据超时。没有断点续传、自动重试上传、自动删除或自动覆盖。上传最终结果不明时刷新确认，重试会创建新的历史备份。

云端清单哈希用于发现截断或损坏，不构成来自服务商之外的来源认证。仍需信任所配置的 WebDAV 服务。失败或取消不提交恢复状态，也不删除本机媒体。

## 后续真实媒体备份

媒体附件独立于应用数据模型和 WebDAV 后端。未来启用附件时使用新容器版本或明确的新 `mediaMode`，增加媒体 ID 到附件的关联、附件长度与 SHA-256、分卷信息、缺失状态及最低读取版本。当前 v2 读取器拒绝非空媒体附件，不会静默忽略。

第一阶段建议将大文件作为独立对象上传，而不是塞进单个 ZIP；数据清单最后提交。附件按内容指纹去重，恢复按需下载，并增加配额预估、断点续传、磁盘空间检查和取消清理。外部原文件与 App 内媒体是否都打包应由明确选项决定。

WebDAV 的单文件、容量、流量与请求额度可能限制大媒体；后端接口不绑定坚果云，后续可接入其他 WebDAV、NAS 或对象存储。自动同步、冲突合并和历史自动清理是独立阶段，不属于当前手动备份。

## 验收边界

离线测试覆盖旧格式往返、新格式无媒体文件、跨平台读取、改名与指纹匹配、别名匹配、歧义拒绝、WebDAV 暂存发布顺序、认证和跳转拒绝、目录边界、校验失败及取消。macOS 和 Android 原生编译用于检查桥接代码。

实际坚果云账号的真实上传、另一平台下载恢复、请求额度和服务端行为仍需配置账号后手动验收。离线测试和两端编译通过不代表真实云端往返已经通过。
