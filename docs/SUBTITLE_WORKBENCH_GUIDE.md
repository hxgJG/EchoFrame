# macOS 字幕工作台

仅 macOS 开放，不上传文件，不修改或复制原视频。导出的是字幕已经烧入画面的新 MP4，字幕不能在其他播放器中关闭。

## 独立制作

1. 在侧栏、文件菜单或视频页打开“字幕工作台”。若当前有音乐/视频播放，会先提示暂停。
2. 选择本地 MP4/MOV 新建项目。建议使用已下载到本机的 SDR、单视频轨、至多一个音轨素材，边长不超过 4096。
3. 点击“导入字幕”选择 SRT、ASS/SSA，检查有效/无效条目摘要后确认；ASS 只保留文字和时间。
4. 没有字幕文件时点击“新增句子”，输入文字及开始/结束时间。也可以先保存未完成草稿，再选择句子，用当前播放画面“标记开始 / 标记结束”。时间可填 `1.250` 秒或 `00:00:01.250`。
5. 字幕整体不合拍时打开“整体校准”：提前/延后 0.1 或 0.5 秒，直接输入秒数，或将选中句开始对齐当前画面。负数提前，正数延后，范围 ±60 秒；取消恢复本次调整，保存可撤销。
6. 调整字号、颜色、上下位置和半透明底色，预览使用与成片相同的原生字幕渲染器。超长或过多重叠字幕需先修正。
7. 点击“导出带字幕视频”，选择新的文件名。导出冻结当前项目版本，之后修改草稿不会改变正在导出的成片。可离开编辑页，重新进入工作台查看任务或取消。

项目修改自动保存；对话框中尚未点击“保存草稿”的输入不算保存。列表可重新打开项目，视频移动/权限失效时“重新选择视频”，字幕草稿仍保留；选择新视频会解除原媒体库绑定。

## 编辑媒体库视频

从视频的“编辑 / 制作字幕”或播放详情的“编辑 / 校准字幕”进入同一工作台。修改和校准默认只保存项目；点击“应用到媒体库”才替换该视频在忆光中的正式字幕。

媒体已移动、被移除或正式字幕已更新时会拒绝覆盖，需从该视频重新打开工作台。自定义字幕不会被重新扫描覆盖。可从播放详情显示/隐藏字幕；隐藏不删除字幕，也不影响成片导出。

“恢复同名字幕”读取已授权媒体文件夹中的同名 SRT/ASS/SSA，没有文件夹授权时改用“导入字幕”。失败或取消不会删除现有草稿。

## 保存与安全边界

- 设置中的应用备份包含字幕项目，不含原视频。恢复为新项目，不覆盖当前项目；跨设备恢复需要重新选择源视频。
- 原视频和已有输出都不能被覆盖。视频范围外的字幕会在导出前提示，确认仅影响本次成片，不删除草稿。
- 导出会重新编码，需要时间和临时空间；空间估计不是最终体积保证。失败时项目仍保留。
- 退出时若正在导出，可选择等待或取消后退出。异常退出不能续编，需重新导出；若异常退出留下不完整目标，核对后手动删除或使用新名称。
- 暂不提供语音识别、复杂 ASS 特效、软字幕轨、多音轨选择、拆分/合并及其他高级剪辑功能。
