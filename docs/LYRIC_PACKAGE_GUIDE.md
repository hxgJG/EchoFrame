# 歌词库与跨设备迁移

入口：设置 → 媒体库 → **歌词库与跨设备迁移**。支持 macOS 和 Android，全程离线，不上传或打包音频。

## 使用流程

1. 在原设备选择「导出跨设备歌词包」。导出当前歌曲正式歌词以及歌词库中启用的待匹配记录，保留毫秒时间、单曲校准、歌名/艺术家/专辑、匹配别名和可取得的文件指纹；不包含设备全局偏移、草稿、本机路径及历史版本。
2. 把 ZIP 文件传到另一台设备，在同一入口选择「导入歌词包」。预览匹配数量、待确认项和覆盖影响，确认后保存。
3. 两个开关独立控制，默认开启：
   - **覆盖已有歌词**：本次导入优先；关闭时已有歌词和单曲校准保留，只补充缺失歌词。歌词库已经有该音频时，关闭覆盖也保留其启用版本的歌词。
   - **同步歌曲展示信息**：同步应用内的歌名、艺术家、专辑；空值/未知值不覆盖有效信息。不重命名文件，也不写入音频标签。原名称保留为匹配别名。
4. 没有对应歌曲时，歌词独立保存在本机歌词库。以后扫描或添加音频，沿用导入时保存的两个开关，自动尝试关联；无需再次选择歌词包。
5. 重名、多版本、旧包或匹配不确定的记录留待手动关联。每条记录的更多菜单可选歌曲、应用历史版本、解除关联或删除。

仍保留原来的「导出全部歌词」功能，其 ZIP 每首一个标准 LRC，适用于其他播放器；**跨设备歌词包**则含版本化的 `lumio-lyrics.json`，应由新版忆光导入，不是音频包。

## 名称与文件对应关系

- 优先使用完整文件 SHA-256 指纹。文件内容相同，修改应用内歌名、艺术家、专辑或仅重命名文件都不影响指纹；多个相同文件同时存在时不猜测，需手动选歌曲。
- 无精确指纹匹配时，尝试当前名称/原名称别名 + 艺术家 + 专辑（双方已知时）+ 时长（误差不超过 1 秒）；或文件名 + 大小 + 时长。只自动应用唯一匹配。
- 指纹不是声学识别：重新编码或写入文件标签会改变完整文件指纹，可能退回信息匹配或需要手动关联。本功能上线前已改过的旧名称无法凭空恢复，但同一文件仍可用指纹匹配。
- 指纹通过本机授权读取音频分块计算，不复制或上传文件。单个文件大于 512 MiB、无权限或读取期间发生变化时跳过指纹；导出提示未取得指纹的数量。扫描只为待匹配指纹对应大小的音频计算，最多 5000 首。
- 普通重复扫描不会反复覆盖已处理歌曲之后的手工修改。文件暂时移除后重新加入会重新匹配；手动解除关联的路径则不再自动关联。

## 保存、历史与撤销

- 歌词库在应用本地数据中独立于歌曲列表保存；没有音频、删除媒体来源或重新扫描不会清空它。与媒体库一起原子写入同一 library 分区，并纳入既有应用备份。
- 新版本启用后旧版本保留为历史记录，不再自动匹配；同内容、同选项的重复导入去重。历史版本可手动应用。
- 「撤销最近操作」可撤销最近一次导入/关联/解除关联/删除，恢复相应歌词、单曲校准和展示信息。后续另行修改或移除的歌曲不会被回退。未匹配歌曲在后续扫描自动应用的变更也记录在最近撤销记录中。
- 删除歌词库记录或解除关联不会删除音频，也不会立即删除已应用到歌曲的歌词。
- 写入失败会报告错误并回滚本次显式操作；未知歌词库版本保留原始数据并禁用编辑，不静默清空。

## 限制与兼容

- 歌词库最多 5000 条（包括历史），歌词库及撤销记录各不超过 32 MiB。ZIP 压缩前后总量均不超过 32 MiB；旧包单个 LRC 不超过 2 MiB，每首不超过 20000 行。
- 旧版 UTF-8 LRC ZIP 可以导入，有效条目和警告先预览；缺少音频时长和指纹，不自动猜测，支持手动关联。旧包中包含独立 `[offset:]` 标签的 LRC 需先将偏移折入时间戳。
- 拒绝不安全路径、符号链接、加密包、重复文件名、校验失败和未知版本；流式限制实际解压大小，不把 ZIP 路径解压到磁盘。
- 当前不做云同步、自动下载歌曲或声学指纹识别。较老版本应用不理解独立歌词库，不建议迁移后回退版本。

## 开发验收

`flutter test --no-pub tool/check_lyric_library_test.dart` 使用合成歌曲和内存存储验证：跨设备数据往返、指纹/别名匹配、先导入后扫描及重启、覆盖选项、展示信息同步、歧义匹配、重复导入、历史记录、撤销、保存失败回滚和异常 ZIP。不是手机真机验收。
