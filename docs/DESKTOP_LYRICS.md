# macOS 桌面歌词

## 使用

- 在「设置 → 桌面歌词」或 macOS「显示 → 开启桌面歌词」开启，默认关闭。
- 悬浮窗跟随应用明暗主题，置顶显示歌曲名、播放状态、当前句和下一句；主窗口最小化后仍可查看。
- 窗口标准尺寸为 720 × 87 pt（窄屏自动收窄），当前句 18 pt、下一句 13 pt，紧凑展示以减少遮挡。
- 按住窗口空白处拖动。点击「锁定」后鼠标穿透，不阻挡底下应用；从设置或「显示 → 解锁桌面歌词」恢复操作。
- 「重置歌词窗口位置」将窗口恢复到主屏底部并解锁。显示器变化时会将窗口限制在可见屏幕内。
- 点击悬浮窗「关闭」只关闭桌面歌词，不停止播放。
- 暂停时保留当前句；拖动播放进度、切歌、导入/移除歌词或调整歌词偏移时同步更新。视频播放时隐藏，回到音频后恢复。
- 没有歌词时显示导入提示，不请求网络或复制媒体文件。

## 实现边界

- 仅 macOS 支持；Android/iOS/HarmonyOS 不显示此开关，不请求悬浮窗权限。
- 使用原生 `NSPanel`，自动更新不激活主应用、不抢键盘焦点；主动重置位置时聚焦歌词窗口以便操作原生按钮。无需辅助功能或屏幕录制权限。
- `lumio/desktop_lyrics` 通道传递当前状态，只有句子、曲目或播放状态变化时才更新原生窗口；不逐进度帧传输整份歌词。
- 时间轴直接复用应用的 `currentLyricIndex` 与歌词偏移；当前句和下一句各占一行，超长内容截断显示。
- 开关、锁定及位置保存在 macOS 应用容器内的 `UserDefaults`（`lumio.desktopLyrics.*`），属于本机窗口偏好，不进入跨平台歌单/设置备份。
- 退出应用时悬浮窗随进程退出；重新启动后按保存的开关与位置恢复。
