# 离线歌词制作

入口：音乐库歌曲的“更多 → 制作歌词 / 继续草稿”，或正在播放页的“更多”。

1. 粘贴歌词，或导入 UTF-8 / UTF-16 TXT（文件最多 2 MB，编辑文本最多 20 万字符）。
2. 点击“按行拆分”。忽略空行，最多 5000 句；重新拆分会清除时间，可撤销。
3. 播放本曲，听到每句开头时点击“标记并下一句”，或按 Enter / F8。空格播放/暂停；输入框内快捷键不拦截正常输入。
4. 可选中某句重打，点击时间直接输入秒数，编辑/拆分、合并下句、插入或删除。Ctrl/⌘ Z 撤销，Shift + Ctrl/⌘ Z 重做（最多 100 步）。
5. 完成后“同步预览”，再“应用到歌曲”或“导出 LRC”。漏标、时间倒序、超出歌曲时长、文本尚未重新拆分时禁止应用/导出。

## 播放与时间

- 时间戳来自播放器实际媒体时间，不使用动画计时，也不乘除播放倍速。
- 支持前后跳 5 秒、倍速及 AB 练习；这些设置作用于当前播放器，退出编辑器后仍保留，可手动恢复 1× 并清除 AB。
- 切换到其他歌曲时，草稿仍属于原歌曲。必须播放原歌曲才能继续打轴；等待时间查询期间切歌、跳转或改变播放状态，会拒绝过期结果。
- 制作预览使用原始媒体时间，不叠加全局/单曲歌词偏移；应用时重置单曲校准。全局显示延迟仍按播放器设置生效。

## 草稿与正式歌词

- 草稿保存在媒体库中对应歌曲的 `lyricDraft` 字段，包含版本、原始文本、逐行文本与可空毫秒时间、选中行。停止编辑 2 秒后自动保存，退出前再次保存；失败会提示，退出时允许重试或放弃未保存修改。
- 草稿不会覆盖正式歌词。只有确认“应用到歌曲”才替换；不修改原音频文件，也不自动写入歌曲所在目录。
- 应用后继续保留草稿。重新扫描同一路径保留草稿，备份随媒体库包含草稿。移除歌曲也会移除对应制作草稿。
- 导出沿用系统文件选择器，生成 UTF-8 LRC（`[mm:ss.SSS]歌词`）；不把设备全局偏移写入文件，也无需先应用到歌曲。
- 未实现自动人声对齐、波形编辑与逐字卡拉 OK；后续可通过生成相同的草稿行数据接入自动对齐，再人工校验。
