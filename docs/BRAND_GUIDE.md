# 忆光（Lumio）品牌与主题规范

## Logo

- 设计语义：佩戴耳机的奶白圆角头像，深青绿音符与播放键分别代表音乐与视频；薄荷头梁和桃粉耳罩带有软垫、包边及浅立体细节，不使用金属材质。
- 正式母版：`assets/branding/lumio_app_icon_master.png`（1024 × 1024，RGB、无透明通道）。
- 应用内轻量资源：`assets/branding/lumio_logo_128.png`，仅用于小尺寸品牌展示，避免运行时解码 1024 像素母版。
- 系统图标：Android、iOS、macOS、HarmonyOS 均由正式母版缩放生成。保留用户确认的浅薄荷满铺背景和主体比例，不裁剪、重新生成或单独修改细节。
- 应用内首页及 macOS 侧栏使用同一份轻量 Logo，不再使用旧的紫蓝声波标识。
- 在 macOS 执行 `python3 tool/sync_brand_icons.py` 可从母版重新同步各尺寸；更换母图时将无透明通道、至少 1024 像素的方形 PNG 路径作为参数。脚本只调用系统自带 `sips`，无需额外安装图像库。

## 主题使用规则

- 音频和视频语义色固定，不跟随用户选择的通用主题强调色变化。
- 混合媒体页面按当前媒体类型使用语义色；纯音频列表使用薄荷绿，纯视频列表使用桃粉色，真正混合时使用通用主题主色。
- 真实封面和视频缩略图保持原色；仅占位图、进度、播放按钮、选中态与媒体类型图标使用语义色。
- 默认使用浅色模式：奶白背景、浅薄荷卡片和按钮、桃粉点缀，深绿仅用于文字、图标及进度等小面积元素。媒体按钮使用浅色容器搭配深绿文字；暗色主题仍可手动选择。视频画面上的文字保持白色，不随主题降低对比度。
- 大面积背景、占位封面使用浅容器色，真实媒体内容不重染色。
- 夜间模式使用炭灰背景和分层灰色容器，避免大面积深绿；音频保留柔和薄荷高亮。设置中的主题方案、明暗模式和强调色独立保存。扩展规则见 [主题架构](THEMING.md)。
- 设置保留四个主题选项。为兼容已有设置和备份，持久化枚举名不改：`blue` → 薄荷绿（默认）、`coral` → 柔桃粉、`teal` → 深青绿、`violet` → 鼠尾草。已有主题模式继续保留；新安装或缺失主题模式时默认浅色，不自动随系统进入深色。
