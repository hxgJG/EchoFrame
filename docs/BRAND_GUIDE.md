# 忆光（Lumio）品牌与主题规范

## Logo

- 设计语义：三层回声框表示本地媒体、回忆与持续播放；金橙音符代表音频，青绿播放块代表视频。
- 正式母版：`assets/branding/lumio_app_icon_master.png`（1024 × 1024，RGB、无透明通道）。
- 应用内轻量资源：`assets/branding/lumio_logo_128.png`，仅用于小尺寸品牌展示，避免运行时解码 1024 像素母版。
- 系统图标：Android、iOS、HarmonyOS 均由正式母版缩放生成。母版背景满铺，使用中心深、边缘亮的靛蓝渐变，确保在纯黑桌面背景上仍能识别图标边界；圆角与异形遮罩交给操作系统处理。
- 禁止给母版重复增加圆角、描边、文字或额外投影；不要单独改变音符、视频符号与三层框的相对位置。

## 主题使用规则

- 音频和视频语义色固定，不跟随用户选择的通用主题强调色变化。
- 混合媒体页面按当前媒体类型使用语义色；纯音频列表使用金橙，纯视频列表使用青绿，真正混合时使用通用主题主色。
- 真实封面和视频缩略图保持原色；仅占位图、进度、播放按钮、选中态与媒体类型图标使用语义色。
- 亮色主题使用较深的金橙和青绿保证可见性；暗色主题使用 Logo 中更明亮的对应颜色。
- 大面积背景只使用语义色的低透明度容器色，避免金橙或青绿抢占正文阅读层级。
