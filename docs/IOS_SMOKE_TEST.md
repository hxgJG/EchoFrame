# iOS 冒烟清单

> 适用版本：1.0.11 及之后。iOS 主链路（导入、扫描、封面、播放、状态持久化）已实现，
> 但从未在真机上完整走查过，发布前请按本清单逐项确认。

## 一、已自动验证（可在 CI 或本机复现）

| 项目 | 结果 | 验证方式 |
|---|---|---|
| 工程可构建（模拟器） | ✅ | `flutter build ios --simulator` |
| 工程可构建（真机，未签名） | ✅ | `flutter build ios --no-codesign` |
| 三个通道编入产物 | ✅ | 产物中可查到 `lumio/app_storage`、`lumio/media_library`、`lumio/playback` |
| 应用可启动并保持运行 | ✅ | `xcrun simctl launch` 后进程存活 |
| Flutter 界面可渲染 | ✅ | 系统日志出现 `FlutterSemanticsScrollView`，无 Dart 异常输出 |
| 插件初始化 | ✅ | 沙盒内自动生成 `Library/Application Support/Lumio/{state,backups,Media}` |

以上只证明「能启动、能渲染、插件已注册」，不证明具体交互正确。

## 二、必须人工走查

### 1. 导入与扫描

- [ ] 设置 → 添加媒体，选择 1 首 MP3：列表出现该曲目，标题/艺术家/专辑来自标签
- [ ] 导入同名文件两次：不覆盖，生成「文件名 (1).mp3」
- [ ] 导入一个视频（MP4/MOV）：出现在视频列表，时长与分辨率正确
- [ ] 同名 `.lrc`、`.srt` 一起导入：歌词与字幕能被识别
- [ ] 冷启动后媒体库仍在（验证 `app_storage` 分区落盘）

### 2. 封面与首帧

- [ ] 有内嵌封面的音频显示封面；无封面显示占位图而不是空白
- [ ] 视频显示首帧缩略图
- [ ] 滚动长列表不卡顿、不闪回占位图（验证内存 LRU + 磁盘缓存）

### 3. 播放

- [ ] 播放 / 暂停 / 拖动进度 / 上一首 / 下一首
- [ ] 切后台再回前台，播放状态与进度正确
- [ ] 倍速切换生效，切换后进度不跳变
- [ ] 一首播完自动下一首（`completed` 事件）
- [ ] 来电或其他应用抢占音频：打断后恢复行为符合预期
- [ ] **视频画面真的出图**（`AVPlayerItemVideoOutput` → `FlutterTexture`，这条最可能出问题）
- [ ] 视频横竖屏画面比例正确，不拉伸

### 4. 已知未实现（不要当缺陷报）

- 后台播放与锁屏控制、控制中心媒体键
- 画中画
- 均衡器、Crossfade
- 文件重命名 / 移动 / 标签写回 / 分享
- 跨端迁移备份、WebDAV、设备互传、应用内更新

界面已按平台能力隐藏这些入口；若发现入口仍然可见，属于缺陷。

## 三、自动化建议

要覆盖上面的交互，需要引入 `integration_test` 并用 `flutter drive` 在模拟器上驱动；
当前仓库的约定是不新增 Widget 测试，因此暂未接入。若后续要长期维护 iOS，
建议单独排期补一条「导入 → 播放 → 重启后仍在」的端到端用例。
