# Lumio 1.0.1

新增 macOS 与 Android 通用的应用数据备份格式，以及应用内 WebDAV 云端备份。设置中的“备份与恢复”可配置坚果云、NAS 或其他兼容的 HTTPS WebDAV 服务，手动上传备份、查看历史并下载恢复。

备份保留设置、歌词及时间调整、歌单、收藏、播放记录和进度、随机播放权重等应用数据。通过媒体指纹和名称别名关联歌曲，修改过名称的歌曲也可匹配；新设备暂时没有歌曲时保留数据，后续添加歌曲再关联。

新版备份不包含实际音视频和封面文件。卸载前必须另外保存 App 内接收的媒体，不能只依靠应用数据备份恢复文件。恢复会覆盖应用数据，不会自动开始播放；外部媒体需重新授权或扫描。

跨平台恢复需要两端使用支持新版格式的版本。旧版备份仍支持在原平台恢复。WebDAV 需要自行配置账号和应用密码，真实服务的上传及跨设备恢复请在配置后验证；不提供实时同步或自动上传。

Android 使用与首个正式版本相同的签名，可覆盖更新。macOS 仍为临时签名，未经过 Apple 公证，下载后手动替换应用，按系统提示处理，不关闭系统安全保护。
