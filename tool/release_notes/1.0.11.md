# Lumio 1.0.11（12）

- 新增专辑与艺术家详情页：点击合集卡片即可查看全部歌曲、总时长与演唱者，支持播放全部和整体加入队列。
- 搜索新增最近 8 条历史记录，可单条删除或清空；搜索结果会随后续扫描与收藏状态自动刷新。
- 播放列表支持「播放全部」与「全部加入队列」。
- 封面改为内存与磁盘两级缓存：内存按 32 MiB 上限淘汰，磁盘缓存 128 MiB，长时间浏览大媒体库不再持续占用内存，冷启动也不必重新解析每首封面。
- 媒体库分组、歌单查询与搜索检索文本改为缓存，万级媒体库下界面重建与按键搜索明显更快。
- 歌词与字幕高亮改为本地插值推进，不再每秒十次读取播放进度，长时间播放更省电。
- 修正搜索页在媒体库变化后结果不刷新的问题。
- 修正字幕整体校准在页面关闭后仍尝试弹出对话框的问题。

Android 支持覆盖升级。macOS 继续保留沙盒并采用临时签名，未经 Apple 公证，首次打开可能需要在系统设置中手动允许。
