# Lumio 1.0.4

优化设置页的窄屏排版。主题方案、明暗模式、默认播放页视图、字幕颜色和字幕位置的选择控件在说明下方显示，不再挤占标题宽度；宽屏保留左右布局，并随系统文字大小调整布局。

修复 Android 更新安装与接收文件共用 Provider 组件类的问题。两者使用独立组件，文件共享范围和权限不扩大；下载校验和打开安装器前，在后台通过共享地址完整读取 APK，核对大小与 SHA-256，读取异常时停止并显示说明。

Android 沿用正式版签名。若当前版本的应用内安装入口出现“解析错误”，请从本发布页用浏览器下载 APK，再用系统文件管理器覆盖安装，不要卸载或清空数据。此修复生效后，后续版本可继续使用应用内安装入口。

macOS 仍采用临时签名，未经过 Apple 公证，仅下载并定位安装包，不自动安装。下载后退出应用并手动替换，不关闭系统安全保护。
