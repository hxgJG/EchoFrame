# Lumio 1.0.2

新增应用更新网络诊断。在设置的“应用更新”中手动检查或下载更新时，记录请求耗时、重定向、响应状态、远端地址、下载速率采样、重试及校验结果，便于分析 GitHub 下载慢或失败的原因。

诊断记录仅保存在本机，下载期间每 5 秒保存一次；失败、取消或离开页面也会保留已有记录。可通过“查看／复制诊断记录”查看并复制日志。记录不包含下载链接中的临时签名参数、账户凭证或媒体内容，不自动上传。

macOS 下载结束后会进行独立的 HEAD 连接探测，补充 DNS、TCP、TLS 和首字节耗时。该探测是另一次连接，可能受缓存和系统代理影响，不代表原下载请求的精确分阶段耗时。

本版用于收集网络信息，未修改 DNS、IP、代理或下载重试策略，也未添加多连接下载或断点续传。测试无 VPN 下载前，请自行关闭 VPN 和代理；App 无法保证网络路径不存在透明代理。

Android 使用与首个正式版本相同的签名，可覆盖更新。macOS 只下载并显示安装包，不自动安装；仍为临时签名且未经过 Apple 公证，下载后手动替换应用，不关闭系统安全保护。
