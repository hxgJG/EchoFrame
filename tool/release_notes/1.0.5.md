# Lumio 1.0.5

统一设置页的标题与说明字号、行距、图标和留白，沿用现有主题配色。窄屏下主题、明暗模式、播放页视图与字幕选项放在说明下方，媒体扫描、添加来源和恢复媒体的操作按钮也不再挤占文字宽度。歌词偏移的减少与增加按钮相邻排列，重置放在最后。

本版采用独立的版本号 1.0.5（6），包含完整的设置页排版调整，避免此前两个 1.0.4（5）构建无法区分的问题。

macOS 仍采用临时签名，未经过 Apple 公证，只下载并定位安装包，不自动安装。下载后退出应用并手动替换，不关闭系统安全保护。
