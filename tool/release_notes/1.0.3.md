# Lumio 1.0.3

应用更新支持断点续传。网络中断会自动尝试续传，手动暂停或离开更新页后保留已下载部分，重新进入页面检查更新即可继续。续传缓存有效期为 7 天，系统清理缓存后需重新下载。服务器不支持续传或返回范围不一致时安全地重新下载，完成后仍校验整个文件的大小、SHA-256 和平台安装包签名。本版未调整 DNS、IP 或代理，也未添加下载加速服务。

设置中的媒体扫描提示与播放错误分开，不再展示旧的播放异常堆栈。扫描信息最多显示两行，完整详情可按需查看，扫描结束后的提示可以关闭。

手机底部播放条新增关闭入口。关闭只在本次 App 运行期间隐藏，不停止音乐，也不删除播放记录或进度；重新播放歌曲时恢复显示，重新启动 App 后也会显示已有记录。悬浮播放器可长按展开播放条后关闭。

更新诊断修正了异常类型覆盖事件名称的问题，并记录续传位置与本次实际传输字节数，避免把已保存进度计算成下载速度。日志仅保存在本机，不自动上传。

Android 沿用正式版签名，可覆盖更新。macOS 仍为临时签名且未经过 Apple 公证，只下载并显示安装包，不自动安装；下载后退出应用并手动替换，不关闭系统安全保护。
